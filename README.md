An exploratory data analysis project completed as part of the **Thiranex Internship — Task 3**.

The project examines roller coaster characteristics and uses statistical analysis and visualization to uncover patterns across speed, height, manufacturers, locations, status, and ride types.

## 🎯 Objectives

- Understand the structure and quality of the dataset
- Analyse missing values and duplicates
- Explore numerical and categorical variables
- Compare roller coaster speed and height
- Study relationships between numerical features
- Analyse manufacturers, locations, types, and operational status
- Communicate findings through clear visualizations

## 🔬 Analysis Workflow

**Inspect → Clean → Explore → Visualize → Interpret**

- Dataset overview and data-quality checks
- Descriptive statistics
- Missing-value and duplicate analysis
- Manufacturer and status analysis
- Speed and height distributions
- Height vs. speed relationship
- Correlation analysis
- Location and coaster-type analysis
- Final observations and conclusions
